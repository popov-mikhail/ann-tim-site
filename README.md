# ann tim — сайт студии дизайна интерьеров

Статический адаптивный сайт-портфолио без сборки и внешних зависимостей.
Опубликован через GitHub Pages:
<https://popov-mikhail.github.io/ann-tim-site/>.

Актуальные задачи хранятся в [`BACKLOG.md`](BACKLOG.md), результаты последнего
технического аудита — в [`AUDIT.md`](AUDIT.md).

## Страницы

- `/` — главная карусель;
- `/projects/` — пять проектов с миниатюрами, переключением кадров и
  полноэкранным просмотром;
- `/projects/<название>/` — подробные страницы пяти проектов с полной
  последовательностью фотографий;
- `/about/` — раздел «О нас», ожидает финальный контент;
- `/publications/` — раздел «Публикации», ожидает финальный контент;
- `/contacts/` — раздел «Контакты», ожидает финальный контент;
- `404.html` — фирменная страница для неверных адресов.

Старые адреса `projects.html`, `about.html`, `publications.html` и
`contacts.html` сохранены как перенаправления на чистые адреса без `.html`.

## Структура

```text
index.html                  главная страница
projects/index.html         галерея проектов
projects/*/index.html       подробные страницы проектов
about/index.html            о студии

scripts/check-site.mjs      автоматическая проверка ссылок и метаданных
```

## Главная карусель

На экранах шире 860 px показываются четыре горизонтальных кадра. На экранах до
860 px используются семь вертикальных кадров в порядке `3, 7, 4, 6, 2, 1, 5`.

Управление:

- автоматическая смена раз в 6 секунд;
- точки карусели и стрелки клавиатуры;
- свайп на мобильном;
- тап по левой или правой половине экрана;
- новый шестисекундный интервал после ручного переключения.

Новый кадр сначала загружается и декодируется, а только затем плавно заменяет
текущий. Это предотвращает белое мерцание в Safari. При включённой системной
настройке «Уменьшение движения» переходы происходят без анимации.

## Изображения и скорость

Горизонтальные кадры имеют WebP-версии шириной 1000, 1600 и 2400 px и JPEG на
случай старых браузеров. Вертикальные мобильные кадры имеют WebP-версии 720,
1000 и 1400 px; прежние JPEG 1000 и 1400 px сохранены как резервный формат.

Логотип отдаётся в WebP шириной 100 или 200 px в зависимости от экрана, а PNG
остаётся резервной версией. Шрифт Manrope хранится локально отдельными WOFF2,
поэтому не требует Google Fonts и кэшируется между страницами.

Для замены изображения нужно сохранить те же имена файлов и размеры либо
обновить соответствующий `srcset` в `index.html`. Положение горизонтального
кадра регулируется переменной `--pos` у изображения.

## Галерея проектов

Сейчас опубликованы:

1. OSTROV I
2. MIHALKOVO PARK
3. AVENUE PARK
4. NOVOPESCHANAYA
5. OSTROV II

Для каждого проекта используются шесть полноразмерных WebP из качественных
исходников и шесть миниатюр из `assets/img/projects/<название>/`. Список
проектов и ссылки на их локальные подробные страницы находятся в начале
`assets/js/projects.js`.

Галерея поддерживает кнопки, клавиатуру, свайпы, прямую ссылку с хешем проекта
и полноэкранный режим. В полноэкранном режиме работают стрелки и `Esc`, фокус
остаётся внутри окна до его закрытия.

Кнопка «Смотреть» открывает отдельную страницу проекта. На ней фотографии
собраны в порядке и группировке публикации Behance: одиночные кадры и пары.
На десктопе высота изображения ограничена относительно окна браузера, поэтому
кадр виден целиком и окружён светлым пространством. На мобильном сохраняются
естественные пропорции и исходная последовательность.

Порядок подробных страниц хранится в `assets/data/project-details.json`. После
его изменения страницы пересобираются командой:

```bash
node scripts/build-project-pages.mjs
```

## Локальная проверка

Из папки проекта:

```bash
python3 -m http.server 8000
```

После этого сайт доступен по адресу <http://localhost:8000/>.

Автоматическая проверка локальных ссылок, изображений, метаданных, sitemap и
комплектности пяти галерей:

```bash
node scripts/check-site.mjs
node --check assets/js/main.js
node --check assets/js/projects.js
```

## Публикация

GitHub Pages публикует содержимое ветки `main`. Сборка не нужна: после push
обновление обычно появляется в течение нескольких минут. Версии в адресах CSS
и JavaScript меняются при важных обновлениях, чтобы браузеры не показывали
старые файлы из кэша.
