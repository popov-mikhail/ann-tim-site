# Бэклог сайта ann tim

Последнее обновление: 7 сентября 2026 года.

Этот файл — основной список задач по сайту. Перед началом новой работы нужно
выбрать одну задачу, уточнить критерий готовности и после публикации перенести
её в раздел «Выполнено».

Обозначения приоритета:

- `P1` — важно для запуска, поиска или стабильности;
- `P2` — заметно улучшает сайт;
- `P3` — можно сделать позднее.

## Ближайшие задачи

| Приоритет | Задача | Критерий готовности |
|---|---|---|
| P1 | Добавить канонические адреса страниц | На всех пяти страницах есть корректный абсолютный `rel="canonical"`; главная указывает на адрес без `index.html` |
| P1 | Создать `sitemap.xml` | В карте перечислены все публичные канонические страницы, файл доступен по публичной ссылке и проходит проверку формата |
| P2 | Добавить структурированные данные студии | На главной есть валидный JSON-LD типа `Organization` с названием, описанием, сайтом, логотипом и только подтверждёнными контактами |
